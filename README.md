# СКАНВОРЛД

Бесконечный сканворд, который растёт после каждого правильного ответа.

## Запуск

Откройте файл `index.html` в любом современном браузере. Сервер и установка зависимостей не нужны.

## Управление

- Нажмите на вопрос или клетку слова.
- Введите ответ с экранной или физической клавиатуры.
- После правильного ответа игра автоматически выберет пересекающееся соседнее слово.
- Перетаскивайте поле одним пальцем или мышью.
- Масштабируйте щипком или колёсиком мыши.
- Кнопка «Центр» возвращает к слову «СКАНВОРЛД».

Прогресс сохраняется в `localStorage` браузера.

## Telegram Mini App

Файл совместим с Telegram WebView. Для публикации разместите `index.html` на HTTPS-хостинге и укажите URL в BotFather.

## Текущая версия

MVP: газетная стилистика, светлая клавиатура, процедурное построение пересечений, сложность 1–10, подсказки и автопереход между словами.
